## Panel-specific overlay

The transformed design is one abstract visual gene, not an infographic and not a user interface. Use a few geometric modules, fine lines, arcs and one tiny index on warm white. One or two functional accent colors come from the photograph. Add a little xerox or risograph grain and a registration error. Reject a complex poster, cyberpunk, random geometry, a template logo and meaningless text.

These overlay rules add to `references/soldier-runtime.md`. They never replace the source brief or the family runtime contract.

Write every selected final PNG directly inside one fresh task directory under `~/Desktop/xxd/xxd-panel-279/` (or the explicit `--out` root). Use collision-safe filenames; do not create source, mode, or size subdirectories and do not generate an automatic contact sheet.
